# Scope réduit — justification (gestion de projet solo)

## Constat

Le cahier des charges IAN/IHN 851 est dimensionné pour un groupe de 3 étudiants sur un semestre.
Ce projet est réalisé **seul**, en **moins d'un mois**, sur un poste sans GPU dédié (Core i5 5e gén, 20 Go RAM).
Le scope est réduit **dès la conception**, par choix de gestion de projet documenté — non subi en fin de parcours.

## Réductions assumées

| Élément | Cahier des charges (groupe de 3) | Scope solo retenu |
|---|---|---|
| Suudu (campement) | 3-4 tentes | 2 tentes |
| Cases galle (concession) | 5-6 cases | 3 cases + dudal + 1 grenier |
| Cycle jour/nuit | Aube → zénith → crépuscule → nuit étoilée | Aube → zénith → crépuscule (nuit étoilée écartée) |
| Scènes "complètes" (éclairage dynamique, feu, audio spatialisé) | Les deux scènes | Une seule scène complète ; l'autre plus sobre |
| Tests utilisateurs | 5 testeurs minimum | 3 testeurs (limite mentionnée explicitement dans le rapport) |
| Personnages | Silhouettes stylisées | Silhouettes statiques, sans animation complexe |

## Ce qui n'est pas négocié

- **Rigueur documentaire et respect culturel** (25% de la grille) : corpus, glossaire, note éthique, sources citées.
- **Cohérence symbolique** (15% de la grille) : orientation, partition genrée, codes spatiaux peuls.

En cas de retard, les coupes se font sur le scope visuel (variantes, détails), jamais sur ces deux axes.

## Objectif

Un build VR qui tourne, stable, cohérent et honnête sur ses choix — plutôt qu'un scope ambitieux à moitié fini.
