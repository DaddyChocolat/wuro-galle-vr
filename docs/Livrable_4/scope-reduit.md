# Scope retenu

## Constat

Ce projet est réalisé en moins d'un mois, sur un poste sans GPU dédié (Core i5 5e gén, 20 Go RAM). Le scope est dimensionné dès la conception plutôt que réduit en urgence en fin de parcours.

La double expérience visée — un campement mobile et une concession fixe — représente à elle seule deux logiques spatiales et deux ambiances lumineuses/sonores distinctes. Les recréer toutes deux avec un niveau de détail maximal dans le temps imparti aurait mécaniquement sacrifié soit la qualité technique, soit la rigueur documentaire. Le choix a donc été de traiter une scène en profondeur et l'autre en version plus sobre, plutôt que de diluer l'effort également sur les deux et risquer de finir avec rien d'abouti.

## Périmètre retenu

| Élément | Périmètre initial envisagé | Périmètre retenu |
|---|---|---|
| Suudu (campement) | 3-4 tentes | 2 tentes |
| Cases galle (concession) | 5-6 cases | 3 cases + dudal + 1 grenier |
| Cycle jour/nuit | Aube → zénith → crépuscule → nuit étoilée | Aube → zénith → crépuscule (nuit étoilée écartée) |
| Scènes "complètes" (éclairage dynamique, feu, audio spatialisé) | Les deux scènes | Une seule scène complète ; l'autre plus sobre |
| Tests utilisateurs | 5 testeurs minimum | 3 testeurs |
| Personnages | Silhouettes stylisées | Silhouettes statiques, sans animation complexe |

## Ce qui n'est pas négocié

Rigueur documentaire et respect culturel : corpus, glossaire, note éthique, sources citées.
Cohérence symbolique : orientation, partition genrée, codes spatiaux peuls.

En cas de retard, les coupes se font sur le scope visuel (variantes, détails), jamais sur ces deux axes.

## Objectif

Un build VR qui tourne, stable, cohérent et honnête sur ses choix — plutôt qu'un scope ambitieux à moitié fini.
